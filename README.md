## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Red Masked Ronin: Desires and Shadows**. This trainer provides convenient single-player assistance for exploration, resource gathering, crafting, character progression, romance interactions, and real-time sword combat. It is designed for the Windows Early Access release and helps reduce repetitive tasks while preserving the game's open-world structure.

**Target Audience:** Players who want to reduce combat difficulty, speed up resource gathering and crafting, simplify sword training, or explore the open world and romance systems with fewer repetitive tasks.

## 📖 Detailed Feature Guide

### Movement & Exploration

Activate Fast Movement after gaining direct control of the ronin. Use it for travel between villages, markets, wilderness areas, and other locations, then disable it before precision interactions or scripted scenes.

### Tools & Inventory

Gather items normally before using the inventory options. Select the desired quantity option only when the inventory screen or item data is active, and avoid changing quest-critical objects unless the game has already registered the required objective.

### World & Environment

The game combines open-world exploration with resource gathering, crafting, environmental interaction, NPC conversations, romance progression, and activities such as mining, woodcutting, and hunting. Freeze Game Time is best used during exploration or preparation and should be disabled before time-sensitive objectives.

### Combat & Weapons

Real-time combat includes sword strikes, heavy swings, blocking, dodging, and sword-training sequences. Activate God Mode before entering a difficult encounter. For training activities, enable Easy Sword Training before starting the exercise and disable it after the sequence is complete.
